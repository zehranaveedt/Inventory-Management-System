##Inventory Management System OPP concepts project

This project is an Inventory Management System made using Object-Oriented Programming (OOP) in Python.

It has a main class called Product and two child classes: Electronics and Grocery.

It uses Encapsulation to hide product data.

It shows Inheritance by reusing the Product class in child classes.

It uses Polymorphism by changing how product info is displayed.

An Inventory class is made to add, remove, and show products.


This system helps manage different types of products in a simple and orgainzed way.
